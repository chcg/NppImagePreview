# Changelog

All notable changes to NppImagePreview are documented here.

## [1.0.0] - Initial Release

### Added

- Image preview on hover
- Preview Image at Cursor
- Thumbnail preview popup
- HTML image path support
- CSS image path support
- PHP image path support
- JavaScript image path support
- PNG support
- JPG / JPEG support
- WebP support
- GIF support
- SVG support
- BMP support
- ICO support
- AVIF support
- TIFF support

### Project

- Initial public source release
- Visual Studio C++ project
- Notepad++ plugin SDK integration
